# Inbox sidebar view switching: bounded re-entry and one qualification path

Base: 2b9358298a24bebe986bf51030d349bfd0293d3e, verified against remote main read-only before work. Separate Temp clone; original dirty checkout unchanged. No push/deployment, production SQL, customer messages, or dependency installs.

Confirmed code paths: selectView started both the page API and router.push/RSC work. The paging hook's replace mode qualified every loaded conversation, in sequential batches of 200, instead of loading only the first complete filtered page. It retained only the current view and exposed that view's total briefly while the next view was loading. These explain local reproduced work; supplied live UI timings include tool overhead and are not query plans.

Paging-mode sidebar navigation now uses Next's supported native History API. One atomic URL supplies view/status/channel/workspace, avoiding an optimistic new view combined with the old scope. Legacy/no-RPC mode retains router navigation. Selected chat/composer components are not remounted by a view-only server navigation. Back/Forward URL sync still works.

Cold views request one server-qualified 30-row page. Search, access, Comments split, Smart View qualification and complete counts remain server-owned, with unchanged API/SQL authorization. Only recent live changes (maximum 200 IDs for 30 seconds) are additionally qualified on first opens, preserving off-page recovery discoveries. Reconnect/resume retains existing bounded catch-up. Pagination remains explicit and keeps its cursor; removing whole-inbox qualification does not truncate the complete server search/count query.

An instance-local cache retains at most six request keys, at most 90 rows per entry, for at most 30 seconds. Keys include status/view/search/channel/workspace/context. Warm rows and their own total display immediately; one quiet read requalifies their visited IDs and fetches page one. No interval/prefetch fan-out was added. Activity/reconnect/configuration changes clear inactive snapshots; unread/pinned/comments also apply current local predicates. Smart View saves/deletes invalidate snapshots. Missing authorized local IDs cannot be reused from inactive cached views, and 401/403 responses clear cached rows. Error states expose retry rather than indefinite loading or another view's counts.
