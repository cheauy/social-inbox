Put your browser logo files in this folder.

Expected filenames (edit BROWSER_LOGO_FILES in
components/settings/active-sessions-view.tsx to change them):

  chrome.png
  safari.png
  firefox.png
  edge.png
  opera.png
  samsung.png
  app.png        (used for non-browser clients, e.g. a mobile app)

Square images, 64x64 or larger, transparent background.
Any file that is missing simply falls back to a grey device icon.
